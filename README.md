# World-Happiness-Report-2015
# World Happiness Analysis (2015)

## Overview
An exploratory data analysis and machine learning project examining the factors associated with happiness across 158 countries in 2015.

## Objectives
- Explore and clean the dataset.
- Analyze happiness scores across countries and regions.
- Examine correlations between happiness and its contributing factors.
- Visualize key patterns and relationships.
- Apply regression models to evaluate the relationship between these factors and happiness scores.

## Dataset
World Happiness Report 2015.

- 158 countries
- 12 variables
- 0 missing values

Main indicators: GDP per capita, Family, Health, Freedom, Trust and Generosity.

## Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Google Colab

## Methodology
1. Data loading and preprocessing
2. Exploratory Data Analysis (EDA)
3. Statistical analysis and correlation
4. Data visualization
5. Machine learning using Linear Regression and Random Forest
6. Model evaluation using R², MAE and RMSE

**Interests:** Data Analysis, Artificial Intelligence and Machine Learning.
